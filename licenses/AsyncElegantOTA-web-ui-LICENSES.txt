Third-party code in the AsyncElegantOTA web page
================================================

The ESP32 repeater images serve a web update page (AsyncElegantOTA 2.2.8,
src/elegantWebpage.h, a pre-built gzipped page). That page bundles the
following works. The copyright banners quoted below are the ones embedded in
the page itself.
